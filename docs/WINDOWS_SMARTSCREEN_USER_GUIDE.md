# Windows SmartScreen - User Guide

**For Windows users seeing the "Windows protected your PC" warning**

## What is this?

Windows Defender SmartScreen is a security feature that blocks unrecognized apps. You're seeing this because the current version of Paprwork is not yet code-signed (we're working on it!).

## Is it safe?

**Yes!** Paprwork is open-source and safe to use. You can review the source code at https://github.com/Papr-ai/paprwork

## How to install anyway

Follow these steps to bypass the warning:

### Step 1: Click "More info"

When you see the SmartScreen warning, click the **"More info"** link at the bottom of the dialog.

![SmartScreen Warning](../assets/smartscreen-warning.png)

### Step 2: Click "Run anyway"

After clicking "More info", you'll see a **"Run anyway"** button. Click it to proceed with installation.

### Step 3: Complete installation

The installer will now run normally. Windows will remember your choice for future updates.

## Future versions

We're working on code signing the application. Future versions will be digitally signed and won't show this warning.
