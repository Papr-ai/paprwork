## SDK Features We're Using

### Messages API (`client.messages.*`)
- **`store()`** - POST `/v1/messages`
  - Saves messages with auto-processing into memories
  - Returns `objectId`, `createdAt`, `processing_status`
  
### Sessions API (`client.messages.sessions.*`)
- **`retrieveHistory()`** - GET `/v1/messages/sessions/{sessionId}`
  - Supports pagination (`limit`, `skip`)
  - Returns `messages[]`, `total_count`, `context_for_llm`, `summaries`
  
- **`compress()`** - GET `/v1/messages/sessions/{sessionId}/compress`
  - Returns hierarchical summaries (short/medium/long-term)
  - 96% token reduction for LLM context
  - Includes `topics`, `ai_agent_note`

## Authentication Flow

```
User Settings → macOS Keychain → Gateway → SDK
    (Add key)    (Secure store)   (Load)   (X-API-Key header)
```

1. User adds `PAPR_API_KEY` in Settings UI
2. Key stored securely in macOS Keychain via Electron IPC
3. Gateway retrieves key on startup
4. SDK initialized with `xAPIKey` parameter
5. SDK sends as `X-API-Key` header to PAPR API
