# Goals archive

Closed goals, kept forever so the record of what was pursued each quarter/year survives. Same block format and ids as `IDENTITY.md` → `## Goals`; Sleep moves blocks here 7 days after they close. Grouped by `Period`, newest first. A goal can be reopened by moving its block back to IDENTITY.md with the same id.
