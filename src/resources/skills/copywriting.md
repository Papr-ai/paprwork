# Copywriting

Write persuasive copy using proven frameworks and techniques.

## Frameworks

### AIDA (Attention-Interest-Desire-Action)
1. **Attention**: Bold headline that stops scrolling
2. **Interest**: Engage with a relevant problem/story
3. **Desire**: Show the transformation/benefit
4. **Action**: Clear CTA (one per piece)

### PAS (Problem-Agitate-Solution)
1. **Problem**: Name the pain point
2. **Agitate**: Make it feel urgent
3. **Solution**: Present your answer

### BAB (Before-After-Bridge)
1. **Before**: Current painful state
2. **After**: Desired future state
3. **Bridge**: How to get there (your product/service)

## Headlines

### Formulas
- "How to [desired outcome] without [common objection]"
- "[Number] ways to [achieve goal] in [timeframe]"
- "The [adjective] guide to [topic]"
- "Why [common belief] is wrong (and what to do instead)"
- "[Do this], [get this result]"

### Rules
- Be specific (numbers, timeframes, outcomes)
- Address one reader directly ("you")
- Promise a clear benefit
- Create curiosity gap

## Email Copy

### Subject Lines
- Keep under 50 characters
- Create urgency or curiosity
- Personalize when possible
- A/B test everything

### Body Structure
1. Hook (first line must earn the second line)
2. Story or proof point
3. Value/insight
4. CTA (one clear action)

## Landing Pages

### Above the Fold
- Headline (benefit-driven)
- Subheadline (how it works)
- CTA button (action verb)
- Social proof (logos, numbers)

### Below the Fold
- Problem section
- Solution/features
- Testimonials
- FAQ
- Final CTA

## Best Practices

- Write for one person, not an audience
- Use simple words (8th grade reading level)
- One idea per paragraph
- Cut ruthlessly — if it doesn't advance the argument, delete it
- Read aloud — if it sounds awkward, rewrite
- CTA should be a verb: "Start", "Get", "Try", "Join"
