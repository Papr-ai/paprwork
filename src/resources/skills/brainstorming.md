# Brainstorming

Structured ideation techniques for generating creative solutions.

## Techniques

### 1. SCAMPER
Apply each lens to the problem:
- **S**ubstitute: What can be replaced?
- **C**ombine: What can be merged?
- **A**dapt: What can be adapted from elsewhere?
- **M**odify: What can be made bigger/smaller/different?
- **P**ut to other use: What else could this be used for?
- **E**liminate: What can be removed?
- **R**everse: What if we flip the approach?

### 2. Mind Mapping
Start with the central problem, branch out:
1. Core problem in center
2. 4-6 main categories branching out
3. Sub-ideas for each category
4. Connect related ideas across branches

### 3. Reverse Brainstorming
Instead of "How do we solve X?", ask "How could we make X worse?" Then reverse each answer.

### 4. First Principles
Break the problem down to fundamental truths:
1. What do we know for certain?
2. What are we assuming?
3. If we started from scratch, what would we build?

### 5. Random Input
Introduce a random word/concept and force connections to the problem. Breaks mental patterns.

### 6. Six Thinking Hats
Examine from six perspectives:
- **White**: Facts and data
- **Red**: Emotions and intuition
- **Black**: Risks and problems
- **Yellow**: Benefits and optimism
- **Green**: Creative alternatives
- **Blue**: Process and organization

## Session Structure

1. **Define** (5 min): Clear problem statement
2. **Diverge** (15 min): Generate ideas without judgment
3. **Cluster** (5 min): Group similar ideas
4. **Converge** (10 min): Evaluate and select top 3-5
5. **Action** (5 min): Define next steps for each

## Rules for Ideation

- Quantity over quality (filter later)
- No criticism during divergent phase
- Build on others' ideas ("Yes, and...")
- Encourage wild ideas (they spark practical ones)
- Write everything down

## Output Format

Save results as a Papr document:
```markdown
# Brainstorm: [Topic]
## Problem Statement
## Ideas Generated (ranked)
### Top 3 Ideas
1. **Idea**: Description, pros, cons, effort
2. ...
## Next Steps
```
